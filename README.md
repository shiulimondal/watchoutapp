🚀 Watchout App | OTT Streaming Platform
A high-performance OTT platform featuring adaptive video playback and secure subscription management.

🛠 Tech Stack
Core: React Native, Expo

State Management: Redux Toolkit

Backend: Firebase

Payment: PhonePe Gateway

✨ Key Features
Video Streaming: Optimized streaming for movies and episodic web series.

Security: Implemented Single-Device Authentication to prevent concurrent logins.

Monetization: Seamless subscription purchases via PhonePe integration.

Maintenance: Built-in Force Update mechanism to keep users on the latest version.
